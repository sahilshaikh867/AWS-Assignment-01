# 🚀 AWS Assignments Repository  

This repo contains step-by-step documentation of AWS assignments done on **Ubuntu CLI** using **IAM, EC2, S3, and more**.  

---

## 📂 Repo Structure
- **Main `README.md`** → Overview of tasks  
- **Task-wise folders** → Each folder has its own `README.md` + `screenshots/`  
- **screenshots/** → Contains step-wise SS for each task  

---

💡 With this structure:  
- Easy navigation 🔍  
- Clean separation of tasks 🗂️  
- Professional repo for assignments 💼
