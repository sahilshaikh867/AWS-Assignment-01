# AWS EC2 & EBS Task 🖥️💾

## About this Task
This task explores **AWS EC2 (Elastic Compute Cloud)** and **EBS (Elastic Block Store)**, two core AWS services for **compute and storage**.  

We focused on **practical objectives** to gain hands-on experience and strengthen cloud management skills.  

---

## ✅ Key Activities

- **Installed AWS CLI** on Ubuntu and verified the installation 🖥️  
- **Created an AMI** (Amazon Machine Image) from an existing instance and launched a new EC2 instance 🔄  
- **Launched EC2 with a custom security group**, restricting access to only your IP 🔒  
- **Created and mounted an EBS volume** on an EC2 instance 💾  
- **Recovered EC2 access** when the key pair was lost 🔑  
- **Took EBS snapshots** and restored a new volume from the snapshot 📦  

---

## 💡 Key Learnings

- Understanding **EC2 instance creation and management**  
- Using **custom security groups** to enhance security  
- Working with **persistent storage (EBS volumes)** and backups  
- Efficient management with **AWS CLI** automation  
- Ensuring **access recovery and business continuity** in emergencies  

---

### ✨ Summary
This task strengthened practical skills in managing **compute resources, storage, and security** in AWS.  
It highlights **real-world cloud management scenarios** like backups, access recovery, and security configuration.
